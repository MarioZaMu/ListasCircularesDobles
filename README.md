# Listas Circulares Dobles: Turnos en una partida de UNO

Taller de **Estructuras de Datos** (Universidad Cooperativa de Colombia, 4.º semestre).

Caso de estudio: los turnos de una partida de UNO modelados con una **lista circular doble** en Python, con frontend en CustomTkinter.

El taller completo está en la carpeta [`uno_circular/`](uno_circular/). Su [README](uno_circular/README.md) explica el caso, por qué se eligió esta estructura, el diagrama de punteros, la instalación y cada método.

## Ejecución rápida (Windows)

```bash
cd uno_circular
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Pruebas: `python -m unittest discover -v` (desde `uno_circular/`).
